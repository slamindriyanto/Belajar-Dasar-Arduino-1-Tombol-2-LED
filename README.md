**Keterangan:**  
DEMO : 1 tombol, 2 LED  
Tekan 1x = LED 1 nyala  
Tekan 2x = LED 2 ikut nyala (kedua LED nyala)  
Tekan 3x = kedua LED mati, lalu mengulang dari awal  
Tombol = pin 8  
LED 1 = pin 9  
LED 2 = pin 10  
Resistor : 330 ohm
